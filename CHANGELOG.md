# Changelog

## 0.1.0 — Initial public release

- Cairo `BurnLedger` supporting creator coupons and referral campaigns.
- Campaign and series supply caps, unique pre-issued coupon IDs and inventory freezing at activation.
- Single-use redemption with per-campaign conversion deduplication and preserved attribution.
- Campaign owner/operator permissions, pausing, closing and expiry checks.
- Public inventory queries and lifecycle events.
- 54 contract tests, including 128 randomized inventory cases.
- Guided TypeScript demo with real Starknet Sepolia transactions.
- Reproducible toolchain, CI checks, public deployment metadata and integration documentation.

### Planned

- Go SDK and integration into Tipper's backend.
- WhatsApp interface built on the backend and SDK.
- Merchant pilots, integration testing and mainnet preparation.
