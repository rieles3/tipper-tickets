# Guided demo

The reference web integration is included in [`demo/`](../demo/). See its [setup guide](../demo/README.md) for local configuration and commands.

Both guided flows create campaigns, issue unique coupon IDs, freeze inventory and redeem existing coupons on Starknet Sepolia. The interface displays per-source attribution and links to transaction receipts. Sample names and simulated visits explain the flow; the issuance and redemption records come from actual transactions.

The demo is a reference integration. The public Go SDK and WhatsApp interface are subsequent phases. It is not a production merchant platform.
